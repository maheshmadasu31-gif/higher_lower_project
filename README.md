# 📊 Higher or Lower Game
 
A simple command-line **Higher or Lower Game built with Python**.
 
In this game, the player is shown two different accounts and must guess which one has more followers. The game continues as long as the player chooses the correct answer, while keeping track of the player's score.
 
## 🚀 Features
 
- Randomly selects accounts from game data
- Displays two accounts for comparison
- Shows account name, description, and country
- Allows the player to guess which account has more followers
- Checks the player's answer automatically
- Keeps track of the player's current score
- Continues the game after every correct answer
- Ends the game when the player gives an incorrect answer
- Prevents the same account from being intentionally used for both comparisons
- Uses ASCII art for the game logo and VS display
 
## 🛠️ Technologies Used
 
- Python 3
- Python functions
- Dictionaries
- Lists
- `random` module
- While loops
- Conditional statements
- User input
- Imported Python modules
